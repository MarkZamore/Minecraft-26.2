# Управление Minecraft 26.2

Сборка сохраняет привычную ванильную раскладку: WASD, Shift для приседания, Ctrl для бега, E для инвентаря, F для второй руки, ЛКМ/ПКМ/СКМ для действий, 1–9 для панели. G открывает быстрые действия, O друзей, P социальные взаимодействия, L достижения. F1/F2/F5/F11 сохраняют стандартные функции. C и X сохраняют операции с творческой панелью.

`launcher/controls-preset.txt` покрывает все 61 зарегистрированное назначение, включая новые настраиваемые клавиши отладки 26.2. `smoothCamera` и `spectatorOutlines` остаются неназначенными, как у Mojang. Диктор в этой версии не зарегистрирован отдельной строкой `key_`; пресет не меняет его настройку и другие параметры доступности.

## Источник и проверка

Реестр `registered-keys.json` прочитан из настоящего patched client Minecraft 26.2 / NeoForge 26.2.0.84 через JDK `javap -p -c`. Снимок хранит SHA-256 клиента и всех модов. Он совпадает со всеми 61 строками `key_` инстанса после запуска. EMI использует существующие ванильные `KeyMapping` в экранах, но не создаёт новых: мод хранит собственные сочетания в `config/emi.css`, а не в `options.txt`. Поэтому пресет не подменяет этот файл и сохраняет штатные R/U просмотра рецептов/применений EMI.

У этой лёгкой сборки нет дополнительных зарегистрированных модовых клавиш, которые требовали бы новых мест на клавиатуре. Пресет даёт игроку способ вернуться к проверенным стандартным назначениям после собственных изменений.

## Намеренные ванильные пересечения

Проверка `KeyMapping.same` в установленном NeoForge сохраняет сравнение одинаковых физических клавиш даже после проверки контекстов. Снимать ванильные функции ради формального отсутствия красных строк было бы неверно. В `allowed-conflicts.json` перечислены точные пары и точная общая клавиша; новых конфликтов такое исключение не разрешает.

- СКМ выбирает блок в обычном режиме и открывает панель наблюдателя в режиме наблюдателя.
- F3 одновременно открывает отладку и служит её модификатором.
- Отладочные действия используют F3 вместе с буквой, цифрой или F4. Они сохраняют свои стандартные клавиши и не меняют обычные WASD, чат, панель, быстрые действия и прочее.
- F3+C копирует местоположение; длительное удержание того же сочетания является штатной диагностической командой аварийного завершения.

## Как обновлять

1. После изменения Minecraft, NeoForge или модов обновить снимок из настоящего клиента:

   ```powershell
   python tools/keybinds/scan_keys.py --client <patched-client.jar> --javap C:/Tools/jdk-25.0.2/bin/javap.exe
   ```

   `--verify` сравнивает источники со снимком без записи. Если новый мод создаёт `KeyMapping`, сканер откажется продолжать: нужно добавить его реальные регистрации в сканирование, а не автоматически снимать неизвестные клавиши.

2. Менять осмысленные назначения в `LAYOUT` файла `build_preset.py`; пересобрать `python tools/keybinds/build_preset.py`. При изменении клавиш пересмотреть точные пары в `allowed-conflicts.json`.
3. Проверить `python tools/keybinds/build_preset.py --check`, `python tools/keybinds/check_preset.py` и `python -B -m unittest discover -s tools/keybinds -p test_preset.py`.
4. Коммит и push в `main` публикуют пресет внутри небольшого `launcher`-архива релиза `pack-latest`. Добавление, редактирование и удаление файла выполняется в репозитории сборки и не требует нового EXE лаунчера с поддержкой синхронизации пресетов. Применение к личному `options.txt` остаётся действием игрока по кнопке.

## Удаление пресета

Чтобы убрать предложение пресета для сборки, удалить `launcher/controls-preset.txt` и отправить изменение в GitHub. Workflow не создаёт файл заново и пропускает проверку отсутствующего пресета; новый манифест больше его не содержит. Инструменты и проверенный снимок можно сохранить для будущего восстановления. При восстановлении сгенерировать файл явно и опубликовать его. Личные назначения игрока при удалении публичного пресета сохраняются.
